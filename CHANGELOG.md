# Changelog

## 0.1.0

- Async Bot API and user/creator API clients.
- Typed update, message, user, bot, chat and file models.
- Aiogram-style Dispatcher, Router, decorators, Command, Keyword and F filters.
- Durable consumer ACK flow and idempotent `Message.answer()`.
- Test/production endpoints, examples and AI/human documentation.
- `inviprog.uz` production endpoints with network-only fallback to legacy `kytsubot.uz`.
